# Vividly

As part of the **"Développeur web et web mobile"** training at **La Plateforme**, this project focuses on creating a web integration using **HTML** and **CSS**.

The main objective of this project was to learn how to create:
- animated loaders
- interactive like buttons using checkboxes

## Technologies Used

- HTML5
- CSS3
